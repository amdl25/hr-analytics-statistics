# HR Analytics – Employee Attrition Analysis (Python & SAS)

Data analysis of the public **IBM HR Analytics Employee Attrition** dataset (1,470 employees), done twice: in Python (pandas, matplotlib) and in SAS.

## Data

The original dataset is split into two tables joined by `EmployeeNumber`:

| File | Content |
|---|---|
| `hr_analytics_dataset.csv` | the full original dataset |
| `employee_personal_data.csv` | age, distance from home, education, education field, gender, marital status, attrition |
| `employee_job_data.csv` | department, job role, income, satisfaction, performance, overtime, years at the company, ... |
| `employee_job_data_with_experience.csv` | job data plus the `ExperienceLevel` column (generated by the script) |
| `employees_merged.csv` | both tables merged (generated by the script, used by the SAS part) |

## Python analysis (`main.py`)
1. Fills missing values: mean for numeric columns, most frequent value for categorical ones.
2. Descriptive statistics of the monthly income: mean, median, standard deviation, minimum, maximum and quartiles.
3. Adds an experience level from total working years: Entry, Intermediate (10 to 14 years) and Senior (over 15 years).
4. Counts employees per department with a dictionary.
5. Shows the distribution of performance ratings for every job role.
6. Compares attrition between employees who work overtime and those who do not (bar chart).
7. Attrition rate by job satisfaction level (bar chart).
8. Average monthly income by education level (line chart).
9. Employees per education field, using a set and a dictionary.
10. Builds a new dataframe with the employees who stayed in the company.

## SAS analysis (`hr_analysis.sas`)
- Imports the two CSV files and merges them by `EmployeeNumber`
- Custom formats for education and satisfaction levels
- Filters employees who stayed and have higher education
- Salary scenarios: +30% for employees with at least 10 years in the company, +10% for the first 20 employees with performance rating 4
- Average monthly income by education level with `PROC MEANS` and `PROC GPLOT`

## Getting started

### Python
```bash
pip install pandas matplotlib
python main.py
```

Run it from this folder, the script reads the CSV files from the current directory.

### SAS
The file paths in `hr_analysis.sas` point to a SAS OnDemand for Academics home folder. Upload `employee_job_data.csv` and `employee_personal_data.csv` to your own folder and update the two `filename` statements.
